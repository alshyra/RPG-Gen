# Aptitude

Aptitudes are spell or abilities that a character can use during gameplay.

They can be offensive (dealing damage to enemies), defensive (protecting the character or allies), or utility-based (providing buffs, debuffs, or other effects).

## Links to character

Characters can acquire aptitudes through unlocking talent via talent trees defined in their archetype (character class).

## Seed

For initial data seeding, refer to the JSON file located at [apps/backend/src/seed/aptitudes.json](../../seed/aptitudes.json)

The seed manager will automatically load this data into the database when the seeding process is executed.
