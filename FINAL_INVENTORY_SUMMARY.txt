🛠️ BACKEND FLOW
================================================================================

1. User clicks class card in StepClassSelection
   ↓
2. Frontend calls: POST /api/characters/{id}/select-class
   {
     "classId": "class_warrior"
   }
   ↓
3. Backend does:
   a) Fetch starter pack for class_warrior
   b) Assign inventory items to character
   c) Calculate stats (base + equipment bonuses)
   d) Save and return character
   ↓
4. Response includes:
   {
     "character": {
       "classId": "class_warrior",
       "inventory": [...],
       "stats": {
         "hp": 14,   // 12 base + 2 from armor
         "pa": 6,
         "pm": 5,    // 6 base - 1 heavy armor
         "vigor": 11, // 10 base + 1 weapon
         ...
       }
     }
   }
   ↓
5. Frontend moves to Avatar selection (STEP 3)

📊 STATS CALCULATION EXAMPLE
================================================================================

Character: Guerrier, Level 1

STEP 1: Base stats by class
  ├─ HP: 12
  ├─ PA: 6
  ├─ PM: 6
  └─ Vigor: 10, Finesse: 9, Mind: 8, Survival: 9

STEP 2: Level-based bonus (level 1 = 0 bonus)
  └─ All stats: +0

STEP 3: Equipment bonuses
  ├─ Épée Longue: +1 Vigor
  ├─ Cotte de Mailles: -1 PM
  └─ Flasque de Vigueur: +0 (consumable)

RESULT:
  HP: 12 + 0 + 0 = 12
  PA: 6 + 0 + 0 = 6
  PM: 6 + 0 - 1 = 5 ✓ (Heavy armor penalty)
  Vigor: 10 + 0 + 1 = 11 ✓ (Sword bonus)
  Finesse: 9 + 0 + 0 = 9
  Mind: 8 + 0 + 0 = 8
  Survival: 9 + 0 + 0 = 9
